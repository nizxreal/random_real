# random_real

Halaman web ucapan sederhana.

## Akses
Buka langsung file `index.html` di browser, atau aktifkan GitHub Pages pada repo ini:
1. Masuk ke **Settings** repo GitHub -> **Pages**.
2. Di **Build and deployment** > **Branch**, pilih `main` dan folder `/ (root)`.
3. Klik **Save**.
4. Website akan aktif dan bisa diakses siapa saja lewat link:
   `https://nizxreal.github.io/random_real/`

## Rencana Pengembangan
- Mengubah/menambah tema ucapan ulang tahun (animasi konfeti, pesan khusus, musik latar).
